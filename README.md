# Discord NGWORD CHECKER

Discord（Web版）でメッセージを送信する際、あらかじめ設定した「NGワード」が含まれている場合に送信を一時ブロックし、確認ダイアログ（アラート）を表示する Tampermonkey / Violentmonkey 用のユーザースクリプトです。

誤爆防止や、特定の単語を含んだメッセージをうっかり送信してしまうリスクを軽減します。

---

## 🌟 主な機能

- **送信前のリアルタイム判定**: `Enter` キーを押してメッセージを送信する直前にチェックを行います。
- **誤爆防止のダイアログ**: NGワードが含まれている場合、「本当に送信しますか？」という確認ダイアログを表示します。
- **NGワードの一括管理**: 拡張機能のメニューから、GUI設定画面を開いてテキスト直接編集または `.txt` ファイルからNGワードを読み込むことができます。
- **複数版対応**: Discord Web版（通常版、PTB版、Canary版）で動作します。

---

## 🛠 インストール方法

### 前提条件
お使いのブラウザに、ユーザースクリプトマネージャーの拡張機能がインストールされている必要があります。
- **Chrome / Edge / Brave 等**: [Tampermonkey](https://www.tampermonkey.net/) や [Violentmonkey](https://violentmonkey.github.io/)
- **Firefox**: [Tampermonkey](https://www.tampermonkey.net/) や [Violentmonkey](https://violentmonkey.github.io/)

### スクリプトの追加手順
1. ブラウザ拡張機能（Tampermonkey等）のダッシュボードを開きます。
2. 「新規スクリプトの追加」を選択します。
3. エディタに `discord-ngword-checker.user.js`（本スクリプトのコード）を貼り付けて保存します。

---

## 🚀 使い方

### 1. NGワードの設定
1. Web版 Discord (`https://discord.com/app` など) を開きます。
2. 拡張機能アイコン（Tampermonkey等）をクリックし、メニューから **「NGワード設定を開く」** を選択します。
3. 設定画面が開きます。
   - **直接入力**: テキストエリアに1行につき1つのNGワードを入力します。
   - **ファイル読み込み**: 「.txtファイルから読み込む」からテキストファイル（UTF-8）を選択して読み込むことも可能です。
4. 右下の **「保存」** ボタンをクリックします。

### 2. メッセージ送信時の動作
- NGワードが含まれていないメッセージ：通常通り送信されます。
- NGワードが含まれているメッセージ：送信が一時停止し、検知されたNGワードの一覧と確認ダイアログが表示されます。
  - **「OK」**: そのままメッセージを送信します。
  - **「キャンセル」**: 送信を中止し、テキストエリアのメッセージを残したまま修正できます。

---

## ⚠️ 注意事項・仕様

- **適用対象**: Webブラウザ版の Discord (`discord.com`, `ptb.discord.com`, `canary.discord.com`) でのみ動作します。デスクトップアプリ版 Discord では動作しません。
- **大文字・小文字**: 判定時は大文字・小文字を区別しません（例: `test` を登録すると `Test` や `TEST` も対象になります）。
- **改行・IME確定**: `Shift + Enter`（改行）や、日本語変換（IME）確定時の `Enter` では判定されません。
- **送信ボタン**: マウスクリックによる送信ボタン（絵文字欄の横などにある場合）には現在対応していません。`Enter` キー送信のみ対応しています。
